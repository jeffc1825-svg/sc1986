# 01 業務需求 — SC1986 詢價型工業電子材料商城

## 定位

SC1986 是工業電子材料供應商的線上型錄與詢價平台。經營模式對標廣華電子商城(shop.cpu.com.tw):

- 大量 SKU 的工業電子材料型錄,規格資訊比行銷文案重要。
- 部分商品有公開參考價,部分顯示「$詢價」。
- 客戶把多個品項放入報價車,逐項填數量與備註後送出詢價單。
- 業務人工確認價格、交期、替代料與加工條件後回覆。

第一階段的交易終點是「可追蹤的詢價案件」,**不是線上付款**。

## 商品範圍

電子零件與耗材、電線/控制線材/連接器/端子、電源/電池/變壓器、開關/感測器/自動控制元件、五金手工具/壓接剝線工具、PCB 加工與焊接工具材料、客製線材與備料需求。

## 目標客戶

工廠採購與設備維護、機台與自動化設備廠商、電控盤與系統整合商、PCB 與線材加工客戶、少量零件散客、長期備料的企業客戶。

## 角色與權限

| 角色 | 能做什麼 |
| --- | --- |
| 公開訪客(免登入) | 瀏覽/搜尋 active 商品、看詳情與規格、加入報價車、送出詢價、取得案件編號 |
| 管理者(登入 + `admin_users.is_active`) | 商品 CRUD、圖片與規格、上下架/封存、CSV 匯入匯出、詢價案件管理與內部備註 |

`admin_users.role` 保留 `owner / admin / staff`,第一階段三者權限相同,出現多人協作需求後再拆分。

## 核心流程

```text
搜尋或瀏覽商品 → 商品詳情 → 加入報價車 → 調整數量/逐項備註
→ 填聯絡資料 → 送出 → RPC 原子建立主檔+品項 → 顯示案件編號
→ Email 通知業務(成敗記錄) → 管理者更新狀態(new→reviewing→quoted→closed/cancelled)
→ 人工回覆正式報價
```

## 三種價格模式(顯示規則)

| 代碼 | 前台顯示 |
| --- | --- |
| `public_price` | 顯示含稅參考價,仍可加入報價車 |
| `quote_only` | 顯示「$詢價」,即使資料庫意外有 price 也不顯示數字 |
| `login_or_quote` | 顯示「報價後提供」,第一階段一律導向詢價 |

## 庫存狀態

`in_stock` 現貨 / `preorder` 可預訂 / `quote_required` 需確認交期 / `discontinued` 停產品(詳情頁保留供辨識,清楚標示不可訂購並引導詢替代料)。

## 發布狀態

`draft` 僅管理端可見 → 人工審核 → `active` 公開 → `archived` 後台保留前台隱藏。
**CSV 匯入、AI 產生或外部整理的商品一律先 `draft`。**

## 第一階段範圍

前台:首頁、商品目錄(搜尋/分類/篩選/分頁)、商品詳情、報價車、詢價表單、成功頁、關於我們、light/dark、SEO。
後台:登入、儀表板、商品管理(含批量)、圖片與規格、CSV 匯入匯出、詢價管理。
系統:Supabase(DB/Auth/Storage/RLS)、詢價通知信、Vercel 部署、Cloudflare DNS。

## 第二階段候選(第一階段穩定後才評估)

會員中心與登入購物、正式購物車與 ECPay/NewebPay 金流、訂單/庫存/物流、AI 客服與 AI 商品草稿、Meilisearch 進階中文搜尋、多角色權限、收藏夾與買過清單(廣華模式的延伸)。

## 第一階段明確不做

付款轉換流程、完整訂單與物流、發票/票據、重量級 commerce backend、自架主機、AI/匯入資料自動發布、複製競品文案或圖片。
